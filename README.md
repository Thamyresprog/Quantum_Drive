# Quantum Drive - Banco de Dados e Hospedagem em Nuvem

Projeto acadêmico desenvolvido para gerenciamento de locação de veículos elétricos.

## Minha contribuição

Responsável pelo desenvolvimento da estrutura do banco de dados e configuração da hospedagem em nuvem, garantindo organização, persistência e disponibilidade dos dados do sistema.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench
- Cloud Database (informar a plataforma utilizada)
- Modelagem de dados
- SQL

## Atividades desenvolvidas

- Modelagem das entidades e relacionamentos
- Criação das tabelas
- Definição das chaves primárias e estrangeiras
- Criação de scripts SQL
- Configuração do banco em ambiente cloud
- Testes de conexão e acesso ao banco

## Estrutura do banco

Principais entidades:

- Cliente
- Veículo
- Categoria
- Locação
- Pagamento
- Agendamento

## Aprendizados

Durante o desenvolvimento foi possível aplicar conceitos de banco de dados relacionais, modelagem, segurança de acesso e utilização de serviços em nuvem.
